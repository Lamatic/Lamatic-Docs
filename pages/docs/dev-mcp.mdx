# Dev MCP (deprecated)

<Callout type="warning">
  **Dev MCP is deprecated.** The `@lamatic/dev-mcp` npm package and its `dev_auth_login` tool (which took an org API key `lt-org-…` and an org ID) are no longer the way to connect an AI assistant to Lamatic. Use **[Lamatic MCP](/docs/mcp/graph-mcp)** at `https://mcp.lamatic.ai/mcp`.
</Callout>

## What to use instead

[Lamatic MCP](/docs/mcp/graph-mcp) is a hosted MCP server. There is nothing to install, and you sign in with your Lamatic account in the browser instead of pasting API keys.

```bash
claude mcp add --transport http lamatic https://mcp.lamatic.ai/mcp
```

See [Lamatic MCP → Connect](/docs/mcp/graph-mcp#connect) for Claude, Cursor, VS Code and other clients.

## Moving from Dev MCP

1. Remove the `lamatic-dev` entry (`npx @lamatic/dev-mcp`) from your MCP client config.
2. Add `https://mcp.lamatic.ai/mcp` as a remote MCP server and sign in when your client asks.
3. Delete `~/.lamatic/config.json` if it is still on your machine. Lamatic MCP does not use it.

| Dev MCP tool | Lamatic MCP |
|--------------|-------------|
| `dev_auth_login` | Not needed. You sign in through the browser |
| `dev_list_projects`, `dev_get_project` | `graph_list_projects`, `graph_get_project` |
| `dev_list_all_flows`, `dev_get_flows` | `graph_list_flows`, `graph_load_flow_details` |
| `dev_create_flow`, `dev_update_flow`, `dev_update_flow_status` | `graph_create_flow`, `graph_update_flow` |
| `dev_deploy_project` | `graph_trigger_deployment` |
| `dev_list_all_deployments`, `dev_get_deployment` | `graph_list_deployments`, `graph_get_deployment` |
| `dev_list_model_creds`, `dev_list_model_providers`, `dev_check_model_status`, `dev_create_model_creds` | `graph_list_models`, `graph_list_model_providers`, `graph_get_model_status`, `graph_create_model_credential` |

Creating, renaming and deleting projects, contexts and integration credentials are done in [Lamatic Studio](https://studio.lamatic.ai).
